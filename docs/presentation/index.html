技术栈与部署

  • 前端：Next.js 14 + Ant Design 5，暖色 parchment 统一视觉
  • 后端：NestJS + Prisma + PostgreSQL，Redis / BullMQ 异步任务
  • Git / CI：Gitea 1.22 + act_runner，模板建仓、Webhook、流水线回写
  • 部署：Docker Compose 单机编排，Caddy 反代，适合百人以内的内网团队
  • 认证：邮箱注册 + 管理员审核；Gitea SSO；员工 PAT 供 MCP / CLI

访问示例：平台 :8080 · Git :8081 · 需同一主机名以支持免密登录

体验与质量

  • 面向非技术同事：简化发布需求、卡片式需求池、引导与「下一步」提示
  • 需求沟通时间线、共同需求人、成果中心（README / 教程 / 下载）
  • 自定义头像、开发模式账号选择器，便于演示与测试
  • 自动化验收：注册 → 建仓 → PR → CI 回写 → 反馈 Issue 闭环（68 项 E2E）
  • Agent API + 远程 MCP + aim CLI：员工用 AI 安全协作与推送代码
